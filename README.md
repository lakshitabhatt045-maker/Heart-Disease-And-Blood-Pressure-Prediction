# ❤️ Heart Disease and Blood Pressure Prediction

## Project Overview
This project focuses on Heart Disease and Blood Pressure Category Prediction using Machine Learning. It analyses patient health-related data and predicts blood pressure categories based on different features such as age, gender, weight, cholesterol, smoking habits and alcohol consumption.

## Objectives
- To analyse cardiovascular health-related data.
- To understand different blood pressure categories.
- To apply Machine Learning for prediction.
- To evaluate model performance using different metrics.
- To develop an interactive web application.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib / Data Visualization

## Dataset
The project uses `cardio_data_processed.csv`, which contains patient-related information and blood pressure category labels.

## Machine Learning Algorithm
**Decision Tree Classifier** is used for predicting blood pressure categories based on the selected input features.

## Features
- Interactive Dashboard
- Exploratory Data Analysis (EDA)
- Data Visualization
- Blood Pressure Category Prediction
- Model Performance Evaluation
- Dataset Preview and Download

## Blood Pressure Categories
- Normal
- Elevated
- Hypertension Stage 1
- Hypertension Stage 2

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure the required Python libraries are installed.
4. Run the following command:

```bash
streamlit run app.py
```

5. Open the local URL displayed in the terminal.
